# 작업 지시서: 비율의 분자·분모 찾을 낱말 적기

## 목적
리포트의 비율 숫자(○○률, ○○ 비중, ○○ 비율 등) 가운데 공시에서 바로 같은 값을 찾지 못한 것이 있다. 이 비율이 **공시에 있는 숫자 두 개를 나눈 것**이면, 코드가 공시에서 분자와 분모를 찾아 직접 나눠 본다.
너는 코드가 공시 항목을 찾을 수 있도록, 분자와 분모가 될 공시 항목의 **이름에 들어 있을 낱말**만 적는다.
숫자를 만들거나 계산하지 않는다. 맞다 틀리다를 판정하지 않는다.

## 데이터 범위
- rows: 리포트 비율 숫자 목록. 숫자마다 rid, item(리포트의 이름), value·unit, as_of(기준), basis(근거 설명), period(코드가 읽은 기간).
- 공시 항목 이름은 한국어 회계 용어다(재무제표 계정, XBRL 한국어 이름표, 공시 본문 표의 줄·열 이름). 영어 약어는 공시 이름에 잘 쓰이지 않는다. 예: 리포트 'CSM'은 공시에서 '보험계약마진', 'ROE'의 분자는 '당기순이익', 분모는 '자본'.

## 쓰기 규칙
- is_ratio: 공시 숫자 두 개를 나눈 비율이면 true. 아래는 false다.
  - 리포트가 정한 가정·추정·목표 값(할인율, 성장률 가정, 목표 비율, 추정 연도 값)
  - 시장 데이터(주가, 지수, 금리)로 만든 비율
  - 리포트가 계산한 조정 값으로 만든 비율(조정 ROE 등)
  - 공시 숫자 두 개로 나타낼 수 없는 것
- numerator / denominator: 낱말 묶음 1~4개. 묶음 하나는 띄어쓰기로 나눈 낱말 1~3개이고, 코드는 공시 이름에 **묶음 안 낱말이 모두** 들어 있는 항목을 찾는다. 묶음끼리는 '또는'이다.
  - 넓게 잡는다. 같은 뜻의 다른 이름(예: '상각'과 '서비스 이전으로 인식', '매출액'과 '영업수익')을 서로 다른 묶음으로 적는다.
  - 낱말은 짧은 회계 용어로 적는다. 문장을 적지 않는다.
- 분모가 잔액(자본, 잔액, 자산 등)이면 연초·연말·평균 가운데 어느 것인지 정하지 않는다. 코드가 셋 다 계산해 본다.
- reason: 한 문장. 무엇을 무엇으로 나눈 비율로 보았는지, 또는 왜 false인지.

## 넘길 것
```json
{"plans": [
  {"rid": "R-05", "is_ratio": true, "numerator": ["보험계약마진 상각", "보험계약마진 서비스 이전"], "denominator": ["보험계약마진"], "reason": "가상생명의 CSM 상각률은 한 해 상각액을 CSM 잔액으로 나눈 것이다"},
  {"rid": "R-09", "is_ratio": false, "numerator": [], "denominator": [], "reason": "리포트가 정한 할인율 가정이라 공시 숫자로 나타낼 수 없다"}
]}
```
위 예시의 회사·숫자는 설명을 위한 가상 사례다.

## 멈출 조건
- rows의 모든 rid에 한 번씩 답한다. 없는 rid를 만들지 않는다.
- is_ratio가 false면 numerator와 denominator는 빈 목록이다.
